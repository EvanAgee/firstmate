# AGENTS.md under the harness instruction cap

## Cap and sizes

The cap comes from the parent repository's #5175 fix, whose size test fails at 32,768 bytes, the Codex project-instruction limit.
Before this change the fork's `AGENTS.md` was 72,406 bytes, so a harness that enforces that cap loaded a truncated contract.
After this change it is 32,647 bytes, 121 bytes under the cap.

`bash tests/fm-agents-size.test.sh` against the original file printed `not ok - AGENTS.md is 72406 bytes; harness instruction cap is 32768 bytes`.
Against the new file it printed `ok - AGENTS.md fits the 32768-byte harness instruction cap`.

## Coverage

`tests/fm-agents-coverage.test.sh` checks that every sentence of the pre-move `AGENTS.md`, frozen in `tests/fixtures/agents-md-before-5175.snapshot`, appears word for word in `AGENTS.md` or some `.agents/skills/*/SKILL.md`.
It also checks that every agent-only internal skill is named by a load trigger in `AGENTS.md`.
The one deliberate rewording, the red-merge rule's cross-reference to the captain instruction precedence section, is removed from the snapshot as the test header describes.

On the first cut of this change, the sentence check reported 113 missing sentences, which is how the review's dropped rules would have been caught.
On control copies of the final tree, the test failed and named the gap after each of three removals: the "Complexity alone is not expansion" sentence, the `firstmate-orca` trigger, and the moved `bin/fm-flow.sh` sentence in `project-management`.
The unchanged copy passed.

`tests/fm-agents-must-stay.test.sh` checks that the preamble, section 1, the captain instruction precedence section, and the section 9 core, including the PR-link rule, stay inline in `AGENTS.md` itself, 61 sentences read from the same snapshot, including review 3's evidence-first pushback sentence.
It catches a sentence that moved into a skill, which the coverage test cannot.
Run against the reviewed `df5aa633` `AGENTS.md`, it failed naming "Whenever a PR is mentioned, include its full `https://...` URL before any shorthand reference."
On control copies of the final tree it also failed after removing hard rule 5's evidence sentence, a precedence sentence, or the internal-term sentence, including when that sentence was moved into `captain-communication`.
